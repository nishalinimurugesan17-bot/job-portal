Job Portal

A web-based Job Portal application developed using Python Django.

Features

- User Registration and Login
- Job Seeker Profile
- Job Listing
- Job Search
- Job Application
- Employer Job Posting
- Application Management

Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

Installation

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Project Status

Developed as a Python Full Stack project.
